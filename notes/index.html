📋 Comment ajouter tes notes
Depuis GoodNotes :
1. Ouvre ton carnet de cours → ⋯ → Exporter → PDF
2. Copie le fichier PDF dans le dossier avihub/notes/
3. Ajoute le fichier dans la liste ci-dessous (dans notes/index.html)

Exemple : { "titre": "Météorologie", "fichier": "meteo.pdf", "matiere": "meteo" }
